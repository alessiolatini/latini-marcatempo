# LATINI MARCATEMPO - test Render

Questa e una versione di prova per verificare pubblicazione via Render e installazione sulla schermata Home del telefono.

## Attenzione
In questa prima prova i dati restano locali nel browser/dispositivo, come nel Marcatempo standalone attuale. Non e ancora la versione multi-dispositivo con database condiviso.

## GitHub
1. Crea un repository, per esempio `latini-marcatempo`.
2. Carica tutti i file di questa cartella nella root del repository.

## Render
1. Dashboard Render -> New -> Static Site.
2. Collega il repository GitHub.
3. Build Command: `echo "no build"`
4. Publish Directory: `.`
5. Crea il sito.
6. Apri l'URL `https://...onrender.com` dal telefono.

## Installazione telefono
- iPhone/Safari: Condividi -> Aggiungi alla schermata Home.
- Android/Chrome: menu -> Aggiungi alla schermata Home / Installa app.
